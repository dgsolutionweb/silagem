Instruções para Imagens da Landing Page

Este documento fornece orientações para as imagens necessárias para a landing page da Trevão Silagem. Para a versão de demonstração, estamos usando a API Lorem Picsum para gerar imagens de placeholder.

Nota: Para o site em produção, substitua essas imagens de placeholder por fotos reais de alta qualidade da Trevão Silagem, mantendo as mesmas dimensões e proporções.

1. Logo (logo.png)

Logotipo principal da empresa, com o texto "Trevão Silagem" em destaque.

Dimensões recomendadas: 200px de largura, formato PNG com fundo transparente.

Placeholder URL: https://dummyimage.com/200x80/2e7d32/fff&text=Trevão+Silagem

2. Logo branco (logo-white.png)

Versão branca do logotipo para uso sobre fundos escuros (rodapé).

Instruções para download das imagens

Para baixar as imagens de placeholder para testes:

  1. Acesse cada URL fornecida
  2. Clique com o botão direito na imagem e selecione "Salvar imagem como..."
  3. Salve na pasta "images" do projeto com o nome especificado
