# Landing Page - Trevão Silagem

Uma landing page responsiva, moderna e de alta conversão para a empresa Trevão Silagem, especializada em venda e prestação de serviços no ramo de silagem para o setor agroindustrial.

## Estrutura do Projeto

```
silagem/
│
├── css/
│   └── styles.css           # Estilos principais da página
│
├── js/
│   └── main.js              # JavaScript para interações
│
├── images/                  # Diretório para imagens
│
├── index.html               # Página principal
├── imagens-instrucoes.html  # Instruções para imagens
└── README.md                # Este arquivo
```

## Características

- **Design Responsivo**: Adaptável para dispositivos móveis, tablets e desktops
- **Performance Otimizada**: Carregamento rápido com lazy-loading de imagens
- **SEO-friendly**: Tags semânticas e metadados otimizados
- **UX Moderno**: Animações sutis e interações intuitivas

## Seções da Página

1. **Hero Banner**: Apresentação principal com call-to-action
2. **Contador de Estatísticas**: Números impressionantes que demonstram credibilidade
3. **Serviços**: Destaque dos principais serviços oferecidos
4. **Diferenciais**: Vantagens competitivas, certificações e depoimentos
5. **Processo**: Passo a passo de como trabalhamos
6. **Portfólio**: Galeria de projetos realizados
7. **FAQ**: Perguntas frequentes para esclarecer dúvidas comuns
8. **CTA Banner**: Chamada para agendamento de visita técnica
9. **Contato**: Formulário de contato e informações da empresa
10. **Rodapé**: Links de navegação e redes sociais

## Tecnologias Utilizadas

- HTML5 semântico
- CSS3 (com variáveis e flexbox/grid)
- JavaScript puro
- AOS (Animate On Scroll) para animações
- Font Awesome para ícones

## Instalação e Uso

1. Clone ou baixe este repositório
2. Abra o arquivo `index.html` em seu navegador para visualizar o projeto
3. Siga as instruções em `imagens-instrucoes.html` para adicionar as imagens necessárias

## Personalização

### Cores
- As cores principais podem ser alteradas no início do arquivo `css/styles.css` nas variáveis CSS (`:root`)

### Imagens
- Substitua as imagens de placeholder na pasta `images/` por imagens reais da empresa
- Consulte `imagens-instrucoes.html` para dimensões e formatos recomendados

### Informações de Contato
- Atualize os dados de contato no formulário e rodapé em `index.html`

## Boas Práticas Implementadas

- **Semântica Adequada**: Uso apropriado de tags HTML5 para melhor SEO e acessibilidade
- **Responsividade**: Design mobile-first com media queries para diferentes tamanhos de tela
- **Otimização**: Compressão de recursos e lazy-loading para melhor performance
- **Comportamento cross-browser**: Compatível com navegadores modernos
